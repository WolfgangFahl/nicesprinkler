# AGENTS.md

Project rules for agents working on nicesprinkler.

## What this is

A computer controlled lawn sprinkler: two stepper motors aim a garden hose
in azimuth and elevation, driven from a Raspberry Pi through TB6600
drivers, with a NiceGUI web frontend for simulation, remote control,
camera view and flow calibration.

## Layout

| path | content |
| :--- | :--- |
| `sprinkler/` | the package |
| `sprinkler/sprinkler_config.py` | dataclasses of the configuration yaml |
| `sprinkler/stepper.py` | GPIO level motor control, mocked off a Raspberry Pi |
| `sprinkler/stepper_view.py` | remote control page |
| `sprinkler/camera.py` | v4l2 camera, mjpeg stream and recording |
| `sprinkler/calibration.py` | flow calibration by bucket and stop watch |
| `sprinkler/sprinkler_sim.py`, `sprinkler_head.py`, `stl3d.py` | 3D views |
| `nicesprinkler_examples/` | example configuration and STL models |
| `images/` | screen captures used by README and issues |

## Rules

- Python 3.10 or newer, PEP 8, type hints and a docstring on every public
  function and class.
- The hardware is real: a command moves a machine under water pressure.
  Never run motor code to try something out.
- Physical constants belong in the configuration yaml, never in the code.
  Pin numbers and angle limits are configuration, not literals.
- A camera frame without its commanded angles is not calibration data.
  Anything that writes frames writes a sidecar with the commanded
  positions beside them.
- Measure rather than assume: state CPU, timing and counts from a run, not
  from expectation.

## Issues

Every issue carries assignee, label and milestone. The body of a
human initiated issue is the dictation; everything an agent has to say is
a comment. Provenance markers:

```
✍️🤖 Agent/Name:                  generated by the agent
🗣️ Author-Name → 🤖 Agent/Name:   dictated by the human
👁️🧑 Author-Name ✓                read by the human and confirmed
```

## Build and test

```bash
scripts/install
python -m unittest discover tests
checkos -p nicesprinkler --local
```

## Never

- No credentials, host names, addresses or infrastructure details in the
  repository, in issues or in screen captures. Crop them out before a
  capture is committed.
